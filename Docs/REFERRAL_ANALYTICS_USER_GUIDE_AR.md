# دليل مستخدم: تحليلات الإحالات

## الغرض

تحول الشاشة بيانات الإحالات الفعلية إلى مؤشرات وترتيبات واتجاهات تساعد الإدارة على تقييم أداء البرنامج، دون عرض سجل العمليات التفصيلي.

## طريقة الوصول

من قائمة الإحالات، اختر **تحليلات الإحالات**.

## المؤشرات الرئيسية

- إجمالي تسجيلات الإحالة.
- إجمالي العملاء الذين انضموا عبر الإحالة.
- إجمالي المكافآت الممنوحة.
- إجمالي نقاط الإحالات الممنوحة قبل العكس.
- متوسط الإحالات لكل عميل.

## الترتيبات

تعرض الشاشة أفضل المحيلين حسب تسجيلات الإحالة، وأكثر أكواد الإحالة استخدامًا، وأفضل العملاء حسب نقاط المكافآت الممنوحة.

## جودة البرنامج

تعرض متوسط الاستخدام لكل كود، ونسب العملاء المسجلين عبر الإحالة، والمكافآت إلى التسجيلات، والعكس إلى المكافآت، وعدد المكافآت المعكوسة.

## النشاط والشجرة

يعرض قسم النشاط عدد الإحالات اليوم وهذا الأسبوع وهذا الشهر والاتجاه اليومي عند توفر البيانات. ويعرض تحليل الشبكة عدد الجذور، وأكبر عمق فعلي، وحجم أكبر شبكة، وصاحبها، دون عرض الشجرة نفسها.

## البحث والتصفية

- ابحث باسم العميل أو كوده أو كود الإحالة.
- حدد تاريخ البداية والنهاية.
- اضغط زر الفلترة لتحديث النتائج.
- اسحب الشاشة إلى الأسفل لإعادة التحميل.

## القيود

الشاشة للعرض والتحليل فقط. لا تنشئ إحالات أو أكوادًا أو مكافآت، ولا تعدل بيانات النظام. إذا تعذر الاتصال، تحقق من تشغيل النظام ثم أعد المحاولة.
