# دليل قوالب الطباعة

## الهدف

هذا الدليل يشرح قسم "إدارة قوالب الطباعة" داخل إعدادات LUMAR ERP. الهدف منه هو تجهيز مستودع تصميمي مركزي لقوالب الطباعة المستقبلية دون ربط فعلي بأي شاشة طباعة أو PDF في الوقت الحالي.

## مكان الوصول

1. من شاشة **الإعدادات** داخل النظام.
2. اختر قسم **إدارة قوالب الطباعة**.
3. ستظهر قائمة تحتوي على التصاميم المسجلة للمستقبل.

## ما الذي يحتويه القسم

القسم لا يقوم بتشغيل أي طباعة الآن، بل يسجل فقط بنية تصميمية لكل قالب محتمل، مثل:

- بطاقة المقاسات
- الفاتورة
- سند القبض
- سند الصرف
- إيصال الطلب
- 3 قوالب احتياطية مستقبلية

## الحقول المعروضة لكل قالب

لكل قالب يتم عرض مجموعة معلومات تصميمية أساسية، وهي:

- اسم القالب
- الاسم البرمجي للقالب
- عرض الصفحة
- ارتفاع الصفحة
- اتجاه الصفحة
- الهوامش الخارجية
- حجم الخط
- اسم الخط
- استخدام رأس المستند
- استخدام شعار الرأس
- اسم المؤسسة
- العنوان
- الهاتف
- لون الحدود
- سمك الحدود
- ملاحظات التصميم

## السلوك الحالي

- لا يوجد ربط فعلي بأي PDF أو شاشة طباعة.
- لا يتم تغيير أي مستند أو قالب تشغيلي موجود.
- لا يتم تطبيق أي تأثير حقيقي على الطباعة الحالية.
- هذا القسم هو مصدر رسمي مستقبلي لتجميع التصاميم قبل ربطها لاحقاً.

## ملاحظات مهمة

- هذا القسم مصمم كمنصة تنظيمية مستقبلية فقط.
- لا يمكن استخدامه الآن لإخراج أي وثيقة أو بطاقة مطبوع.
- كل إضافة أو تعديل في القوالب يتم على مستوى التصميم فقط، وليس على مستوى التشغيل الفعلي.

## عند الحاجة لاحقاً

عند البدء في مرحلة الربط الفعلي بين القوالب والطباعة، يمكن استخدام هذا القسم كمصدر للإعدادات الأساسية ثم ربطها تدريجياً بالطبعات الفعلية. حتى ذلك الوقت يبقى القسم في حالة تصميمية محايدة وغير فعال.
