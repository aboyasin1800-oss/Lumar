# دليل إدارة أجهزة المسح

## الغرض

تُستخدم هذه الشاشة لإدارة أجهزة المسح المسجلة في النظام، مع إمكانية إضافة جهاز جديد، تعديل بياناته، وتفعيل أو إيقاف استخدامه عند الحاجة.

## طريقة الوصول

- افتح قسم **الإعدادات** من القائمة الرئيسية.
- اختر بطاقة **إدارة أجهزة المسح**.

## الحقول والأزرار

### 1) ScannerCode
- رمز الجهاز المختص بالمسح داخل النظام.
- يجب أن يكون فريداً ولا يتكرر مع ماسح آخر.

### 2) ScannerName
- اسم الجهاز الظاهر في النظام.
- يستخدم لتمييز أجهزة المسح في قائمة الإدارة.

### 3) Description
- وصف اختياري يوضح用途 الجهاز أو موقعه.
- يمكن تركه فارغاً إذا لم تكن هناك تفاصيل إضافية.

### 4) الحالة
- يعمل زر التبديل لتفعيل أو إيقاف الجهاز.
- عند إيقاف الجهاز، يمنع استخدامه في عملية المسح والتتبع.

### 5) حفظ
- يحفظ البيانات المضافة أو المعدلة في قاعدة البيانات عبر API المسموح.

### 6) تعديل / إيقاف / تفعيل
- يمكن تعديل إعدادات أي ماسح من القائمة.
- يمكن إيقاف أو تفعيل الماسح بسرعة من بطاقة الشاشة.

## الاستخدام الأساسي

1. اضغط **إضافة أول ماسح** أو زر الإضافة.
2. أدخل رمز الجهاز واسم الجهاز.
3. اختياريًا أضف وصفاً.
4. اختر حالة التفعيل.
5. اضغط **حفظ**.
6. استخدم زر التفعيل/الإيقاف في القائمة لتحديث الحالة بسرعة.

## رسائل الخطأ المتوقعة

- "رمز الماسح مطلوب." إذا ترك الحقل فارغاً.
- "اسم الماسح مطلوب." إذا ترك الاسم فارغاً.
- "بيانات الماسح غير صحيحة." عند وجود مشكلة في البيانات.
- "رمز الماسح موجود بالفعل." عند تكرار رمز الجهاز.

## القيود

- لا يتم إنشاء أي جدول أو ترحيل جديد.
- لا يتم ربط الماسح بأي مرحلة إنتاج أو موظف بشكل مباشر داخل هذه الشاشة.
- إدارة الماسح تقتصر على سجل الجهاز نفسه، بما يتوافق مع سياسة النظام الحالية.
