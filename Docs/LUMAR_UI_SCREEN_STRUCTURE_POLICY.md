# سياسة هيكل شاشات لومار

## النطاق

هذه السياسة تخص واجهة Flutter فقط. لا تغيّر هذه البنية قاعدة البيانات أو واجهات API أو منطق CRUD أو النماذج أو المستودعات.

## مصدر الشاشات

- تبقى الشاشات التشغيلية الحالية في `lib/screens/` كمصدر متوافق وآمن للمحتوى الحالي.
- تضع المجلدات الفرعية في `lib/screens/` الشاشات ضمن الوحدات المعتمدة.
- تستخدم أغلفة أو إعادة تصدير للشاشات التشغيلية القائمة؛ لا تنسخ منطق الشاشة أو تنشئ شاشة تشغيلية مكررة.
- كل شاشة غير منفذة تعرض عنوانًا ووصفًا عربيين من خلال `StructurePlaceholder` فقط، ولا تحتوي بيانات تجريبية أو منطق أعمال.

## التنقل

- لوحة البداية هي شبكة الوحدات الرئيسية ولا تعرض القائمة الجانبية افتراضيًا.
- عند فتح وحدة أو شاشة فرعية تظهر القائمة الجانبية، ويمكن إظهارها أو إخفاؤها من زر القائمة في الرأس.
- تحفظ حالة ظهور القائمة محليًا باستخدام المفتاح `lumar_sidebar_visible`.
- تعرض القائمة الوحدات الرئيسية فقط؛ تنقل بطاقات الوحدة إلى شاشاتها الفرعية عبر المسارات `/structure/<title>`.

## معايير الواجهة

- كل النصوص الجديدة عربية وتلتزم باتجاه RTL والثيم المركزي.
- يجب أن تعمل الشاشات مع سياسة لوحة المفاتيح العامة، بما فيها Escape للرجوع.
- يجب أن تحترم مقياس الواجهة العام ولا تستخدم `Transform.scale` لتكبير المحتوى.
- يجب دعم Dark Mode وLight Mode في كل شاشة جديدة أو معاد بناؤها.
- يجب أن تملأ مكونات الشاشة مساحة العرض بصورة متوازنة.
- يجب أن تتكيف الأعمدة والبطاقات مع العرض دون فراغات غير مبررة أو قص للمحتوى.
- يجب تطبيق نظام Responsive فعلي عبر `AppBreakpoints` وطبقة التصميم المركزية، وليس الاكتفاء باستخدام `LayoutBuilder` أو `MediaQuery` محلياً دون مرجع مركزي.
- لا يجوز اعتماد شاشة تعمل بشكل جيد في وضع واحد فقط.
- أي شاشة جديدة يجب أن تبدو صحيحة عند UI Scale صغير، طبيعي، وكبير، مع المحافظة على التوزيع، القراءة، المسافات، والتفاعل، دون تداخل أو قص أو كسر للتخطيط.
- العناوين لا يجوز أن تكون ضخمة أو مبالغاً فيها؛ يجب أن تكون واضحة، مهنية، متناسقة، مع استهلاك أقل للمساحة الرأسية، مع إعطاء الأولوية للبيانات والمحتوى التشغيلي وليس للعناوين الضخمة أو الزخارف الكبيرة.
- تظل `AppTheme` و`AppTypography` و`AppSpacing` و`AppDimensions` و`AppBreakpoints` و`AppSurface` و`AppIcons` المرجع التنفيذي الموحد لكل شاشة.
