# سياسة لوحة المفاتيح في LUMAR ERP

الحالة: معتمدة

## Enter

- ينتقل Enter إلى الحقل القابل للإدخال التالي داخل النموذج.
- ينفذ Enter الإجراء الإيجابي الأساسي عند الحقل الأخير، مثل الحفظ أو البحث أو تسجيل الدخول.
- لا يستخدم Enter للإلغاء أو الإغلاق أو الحذف أو التراجع.
- لا تكون الأزرار السلبية ضمن مسار التركيز الذي ينفذ بواسطة Enter.

## Escape

- يغلق Escape مربع الحوار أو يعيد المستخدم إلى الشاشة السابقة.
- لا ينفذ Escape إجراء حفظ أو حذف.

## الجداول ومربعات الحوار

- يفتح Enter العنصر المحدد في الجداول عند توفير شاشة تفاصيل له.
- في مربع الحوار، ينفذ Enter الإجراء الإيجابي وEscape الإلغاء أو الإغلاق.

## الالتزام

كل شاشة أو نموذج جديد يجب أن يطبق هذه السياسة باستخدام غلاف `KeyboardPolicy` المركزي، مع تحديد انتقال الحقول وإجراء الحقل الأخير صراحة.
