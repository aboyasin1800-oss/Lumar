# دليل مستخدم: سجل أحداث الإحالات

## الغرض
تعرض الشاشة التسلسل الفعلي لأحداث الإحالات المسجلة في النظام، مثل تسجيل الإحالة ومنح المكافأة وعكسها، مع تاريخ كل حدث والنقاط الواردة معه.

## طريقة الوصول
من قائمة الإحالات، اختر **سجل أحداث الإحالات**.

## عناصر الشاشة
- **بحث:** البحث باسم العميل أو كود العميل أو كود الإحالة.
- **نوع الحدث:** عرض نوع محدد أو جميع الأحداث.
- **من تاريخ / إلى تاريخ:** تقييد النتائج بفترة زمنية.
- **تحديث:** إعادة تحميل الأحداث من النظام.
- **بطاقات الملخص:** تعرض أعداد التسجيلات والمكافآت الممنوحة والمعكوسة وصافي نقاط الإحالات بعد احتساب أحداث المنح والعكس ضمن النتائج الحالية.

## عرض التفاصيل
اضغط على أي حدث لعرض نوعه وتاريخه والمحيل والمحال وكود الإحالة ورقم الطلب إن وجد والنقاط والملاحظات.

## الأنواع
تظهر الأنواع المعروفة بالعربية: **تسجيل إحالة**، **منح مكافأة إحالة**، و**عكس مكافأة إحالة**. وأي نوع آخر محفوظ في النظام يظهر باسم عربي عام عند عدم وجود ترجمة محددة.

## ملاحظات
- تعرض الشاشة الأحداث المسجلة فعليًا فقط، ولا تنشئ أحداثًا أو تحسب نقاطًا جديدة.
- إذا لم توجد أحداث مطابقة للفلاتر، تظهر رسالة تفيد بعدم وجود نتائج.
- عند تعذر الاتصال أو تحميل البيانات، استخدم زر التحديث وتحقق من اتصال النظام.
