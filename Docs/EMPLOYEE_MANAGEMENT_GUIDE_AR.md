# دليل استخدام شاشة الموظفين

## الغرض

تُستخدم شاشة الموظفين لإدارة سجلات العاملين داخل نظام LUMAR ERP، بما في ذلك:

- إضافة موظف جديد
- تعديل بيانات موظف موجود
- إيقاف موظف مؤقتاً
- إعادة تفعيل موظف
- البحث والفحص السريع للموظفين

## الوصول إلى الشاشة

1. من القائمة الرئيسية للنظام، افتح قسم الموظفين.
2. ستظهر قائمة بجميع الموظفين المسجلين في النظام.
3. يمكن استخدام البحث حسب الاسم أو رقم الموظف.

## الحقول المتاحة

عند إنشاء أو تعديل موظف، تظهر الحقول الرسمية التالية فقط:

- EmployeeCode
- FullName
- DepartmentId
- BasicSalary
- PhoneNumber
- HireDate
- Status

ملاحظات:

- لا تستخدم الحقول القديمة مثل EmployeeName أو Phone أو BaseSalary أو FixedSalary في هذه الشاشة.
- EmployeeCode مطلوب.
- FullName مطلوب.
- DepartmentId مطلوب.
- BasicSalary يجب أن يكون أكبر من صفر.

## إضافة موظف

1. اضغط زر "إضافة موظف" في أعلى شاشة القائمة.
2. املأ الحقول المطلوبة.
3. اختر القسم المناسب.
4. أدخل الراتب الأساسي بشكل صحيح.
5. اضغط "حفظ".
6. في حال نجح الحفظ، تظهر رسالة نجاح ويُحدّث العرض تلقائياً.

## تعديل موظف

1. افتح تفاصيل الموظف.
2. اضغط أيقونة التعديل.
3. عدّل الحقول المطلوبة.
4. احفظ التغييرات.
5. سيتم تحديث التفاصيل مباشرة بعد الحفظ.

## إيقاف / إعادة تفعيل موظف

1. افتح تفاصيل الموظف.
2. استخدم زر "إيقاف" أو "إعادة تفعيل" حسب الحالة الحالية.
3. سيتم تحديث الحالة في قاعدة البيانات عبر واجهة API المعتمدة فقط.
4. ستظهر رسالة نجاح أو فشل واضحة عند تنفيذ العملية.

## منع التكرار

- إذا كان EmployeeCode موجوداً بالفعل، يمنع النظام الإرسال ويظهر رسالة واضحة.
- لا يمكن حفظ موظف جديد بنفس رقم الموظف في نفس المؤسسة.

## رسائل الخطأ

عند وجود خطأ، قد تظهر رسائل مثل:

- EmployeeCode مطلوب.
- FullName مطلوب.
- DepartmentId مطلوب.
- BasicSalary يجب أن يكون أكبر من صفر.
- رقم الموظف موجود بالفعل.
- تعذر حفظ بيانات الموظف.

## القيود

- لا تُستخدم وظائف الحضور أو الوثائق أو الرواتب أو التتبع داخل هذه الشاشة.
- لا تُجرى أي تغييرات مباشرة على قاعدة البيانات خارج واجهة API الخاصة بالموظفين.
- لا يُسمح بعمليات الحذف من هذه الواجهة.

## الخلاصة

شاشة الموظفين الآن قادرة على:

- إضافة موظف
- تعديل موظف
- إيقاف موظف
- إعادة تفعيل موظف

من خلال واجهة Flutter الرسمية، مع التحقق من صحة البيانات وتحديث القائمة والتفاصيل فوراً بعد الحفظ.
