# إعدادات الطباعة

## الغرض
تُستخدم هذه الشاشة لإدارة رأس المستندات المطبوعة، مثل الفواتير وبطاقات المقاسات والعقود والمستندات المالية عند توفر مسار طباعتها. يمكن اختيار صورة للرأس أو استخدام رأس نصي يتكون من اسم المؤسسة والموقع والهاتفين. لا تُنشئ هذه الإعدادات أي جدول أو عمود جديد في قاعدة البيانات، بل تُخزن في إعدادات النظام الحالية داخل `System_Settings`.

## طريقة الوصول
من قائمة الإعدادات في النظام، اختر قسم **إعدادات الطباعة**.

## الحقول الأساسية
- `استخدام صورة رأس المستند`: يحدد ما إذا كان المستند يعرض الصورة أم الرأس النصي.
- `رابط أو مسار صورة الرأس`: عنوان أو مسار الصورة المستخدمة في رأس المستند.
- `اسم الشركة / المؤسسة`: النص الذي يظهر في رأس الطباعة إذا لم يتم استخدام الشعار.
- `الموقع`: عنوان المؤسسة أو الفرع.
- `الهاتف الأول`: رقم الاتصال الرئيسي.
- `الهاتف الثاني`: رقم الاتصال الاحتياطي.

## خطوات الاستخدام
1. افتح شاشة إعدادات الطباعة.
2. عدّل الحقول المطلوبة.
3. فعّل أو أوقف خيار استخدام الشعار حسب الحاجة.
4. اضغط على **حفظ إعدادات الطباعة**.
5. أعد فتح شاشة الطباعة لتأكيد ظهور التغييرات في المستند المطلوب.

تُنشأ المستندات الحالية بحجم A5 عمودي، مع بقاء الرأس نفسه قابلاً لإعادة الاستخدام في الفاتورة وبطاقة المقاسات والعقد.

## القيود أو السلوكيات المهمة
- لا تُنشئ هذه الشاشة أي Migration أو عمود جديد.
- تعتمد على المفاتيح الحالية في `System_Settings` فقط.
- إذا لم يُعطى رابط شعار، سيعرض النظام الاسم أو نص الرأس بدلاً منه.
- لا توجد متابعة لإحصائيات الطباعة أو سجل الطباعة في هذه المرحلة.
